# Task 4：思考题

## 1. Make 和简单的 build.sh 有什么区别？

Make只编译你改过的代码(根据文件的时间判断那些需要重新编译),不会浪费时间去编译没有改动过的代码;build.sh(shell脚本),不管代码是否改动,所有文件全部重新编译一次

## 2. CMake 是编译器吗？

执行 `cmake --build build` 时，最终是谁在编译 C 源文件？

CMake不是编译器,只生成负责编译的规则文件(Makefile),让底层make和gcc干活,将c源代码编译成机器代码的是底层的c编译器(如gcc)



## 3. 为什么不希望每次都重新编译所有 `.c` 文件？

项目文件多时,全部编译特别慢,而且很多没有修改过的代码没有必要重复编译,所以只编译修改过的文件可以节约时间,提高开发效率.
