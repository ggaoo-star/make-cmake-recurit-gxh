# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
2. 编译
3. 汇编
4. 链接

建议控制在 300～500 字，不需要展开复杂细节。
1 预处理:展开#include,将头文件内容复制粘贴到当前代码所在位置,合并进代码;#define进行文字替换(宏定义=给一段文字起一个别名,做文字替换);条件编译:根据有没有定义某个宏,选择保留或者删除一部分代码.
2 将预处理后的c语言代码,做语法语义检查,翻译成汇编语言代码,生成.s汇编文件.
3 将汇编指令翻译成机器码(二进制),生成目标文件(.o)
4 链接:(链接器)把刚才生成的多个".o"文件和系统自带的库啊(比如printf main)装拼在一起,补齐内存地址,最后生成可以直接运行的可执行文件.
